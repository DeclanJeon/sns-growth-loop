# SNS Growth Loop

게시를 반복하며 실제 반응을 관찰하고, 다음 콘텐츠에서 검증할 한 가지를 정하도록 돕는 AI 에이전트 스킬입니다. 분석 마비와 감에 의존한 반복을 줄이고, **기준선 → 작은 실험 → 게시 → 피드백 → 다음 결정**의 학습 루프를 만드는 것이 목적입니다.

이 스킬은 조회수나 팔로워 증가를 보장하지 않습니다. 매일 게시하라고 일률적으로 권하지도 않습니다.

## 이런 요청에 사용하세요

- 채널 성장을 어디서부터 시작할지 정하고 싶을 때
- 반복해서 올리는 콘텐츠의 결과를 복기하고 다음 실험을 고를 때
- 시청 유지율, 클릭, 저장, 공유, 팔로우·구독 전환 등 제공한 지표를 진단할 때
- 현재 제작 빈도와 자원에 맞는 지속 가능한 실험 계획이 필요할 때
- YouTube, Instagram, TikTok, Threads, X 등에서 게시물별 학습 루프를 만들 때

캠페인 문안이나 단일 게시물 제작, 영상 제작 자체가 요청이라면 해당 제작 스킬을 사용하세요. 이 스킬은 채널 단위의 반복 개선과 분석에 초점을 둡니다.

## 작동 방식

1. **상황 파악:** 플랫폼, 포맷, 대상 시청자, 목표(발견·유지·커뮤니티·전환), 지속 가능한 게시 빈도를 정리합니다.
2. **기준선 확인:** 제공된 지표와 콘텐츠에서 직접 관찰한 사실을 가설과 구분합니다. 자료가 부족하면 부족한 점을 밝히고 콘텐츠에서 시작할 테스트를 제안합니다.
3. **한 가지 실험 선택:** `문제 → 가설 → 바꿀 요소 하나 → 주요 지표` 형식으로 실험을 정의합니다. 가능한 한 다른 큰 변수를 유지합니다.
4. **약속 전달:** 영상은 제목·표지의 약속을 첫 5초 안에 보여주는 방법을 검토합니다. 텍스트·이미지는 첫 화면과 플랫폼의 고유 포맷에 맞게 적용합니다.
5. **두 번 피드백 수집:** 기획·촬영·편집 중 즉시 메모하고, 데이터가 쌓이면 실제 콘텐츠와 플랫폼 분석을 함께 복기합니다.
6. **다음 결정:** 같은 플랫폼·포맷의 게시물을 비교하고, 효과가 있었던 요소도 재시험합니다. 게시물 하나만으로 인과를 단정하지 않습니다.

## 사용하는 방법

### Codex에 설치

이 저장소는 별도 실행 파일이나 패키지 설치가 필요 없는 Markdown 기반 스킬입니다. Codex의 사용자 스킬 경로에 복제하세요.

```powershell
# 새로 설치
git clone https://github.com/DeclanJeon/sns-growth-loop.git "$HOME/.codex/skills/sns-growth-loop"

# 이미 설치한 경우 업데이트
git -C "$HOME/.codex/skills/sns-growth-loop" pull
```

복제 후 에이전트가 스킬을 검색하는지 확인하세요. 환경에서 스킬 목록을 새로 고쳐야 한다면 새 세션을 시작하세요. 다른 에이전트에서는 해당 에이전트가 지원하는 스킬 디렉터리에 이 저장소를 설치해야 합니다.

### 에이전트에 요청하기

스킬을 읽는 에이전트에게 평소처럼 목표와 가진 자료를 전달하세요. 스킬 설명과 일치하는 성장·복기 요청에서 자동으로 선택될 수 있습니다. 특정 제품에서 자동 선택이 지원되지 않으면 `sns-growth-loop 스킬을 적용해서 ...`라고 명시하세요.

예시:

> 최근 YouTube 쇼츠 8개의 조회수, 노출 클릭률, 평균 시청 지속 시간과 각 영상 주제를 정리했어. 목표는 신규 시청자 발견이야. 기준선과 부족한 데이터를 구분하고, 다음 쇼츠에서 검증할 변화 한 가지와 주요 지표를 정해줘. 매일 업로드는 어려워.

> 인스타그램 릴스 최근 게시물의 도달·저장·공유·프로필 방문·팔로우 수치를 줄게. 계정 목표는 팔로우 전환이야. 숫자만으로 원인을 단정하지 말고, 다음 실험과 결과를 확인할 시점을 제안해줘.

가능하면 플랫폼·포맷·목표, 최근 게시물의 비교 가능한 지표, 게시물 링크나 대본, 제작 여건을 함께 제공하세요. 민감하거나 비공개인 분석 자료는 공유 범위를 확인하고 필요한 내용만 붙여 넣으세요. 에이전트가 계정 데이터에 자동 접근한다고 가정하지 마세요.

### 기대할 답변

성장 계획이나 진단은 최소한 다음 내용을 포함해야 합니다.

- 확인된 기준선과 아직 모르는 점
- 다음 게시물에서 바꿀 한 가지와 그 이유
- 그 실험의 주요 지표 및 확인 기간
- 제작 중 바로 기록할 피드백
- 결과에 따라 다음에 내릴 결정

## 범위와 한계

이 스킬의 참고 플레이북은 [흰지로의 오답노트 영상](https://youtu.be/eS7_ODoH28E)의 조언을 Flucto 한국어 전사에 기반해 정리했습니다. **단일 영상에서 나온 조언을 작업 루프로 정리한 것이며, 검증된 종합 성장 공식이나 플랫폼별 최신 가이드가 아닙니다.**

- 영상의 5초 약속 전달, 첫 30초 유지율 수치, 44%→65% 사례는 출처가 보고한 주장·사례일 뿐 보편적 기준이나 인과 증명이 아닙니다.
- YouTube의 지표 정의나 기준을 다른 플랫폼에 그대로 적용하지 않습니다. 플랫폼별 최신 수치·기능은 공식 자료에서 따로 확인해야 합니다.
- 분석 데이터가 없으면 이를 지어내지 않고, 무엇이 확인되지 않았는지 밝힙니다. 비율을 계산할 때는 분자·분모·기간을 함께 적습니다.
- 한 게시물이나 지표만으로 성공 또는 원인을 단정하지 않고, 성장이나 바이럴을 약속하지 않습니다.
- 원본 Flucto 전사 파일은 저작권·배포 범위를 고려해 이 저장소에 포함하지 않았습니다. 근거와 요약은 `references/video-derived-playbook.md`를 참고하세요.

## 저장소 구성

```text
SKILL.md                              # 에이전트가 읽는 트리거와 작업 지침
references/video-derived-playbook.md # 출처 기반 조언, 복기 템플릿, 적용 한계
evals/evals.json                    # 재사용 가능한 시나리오와 평가 기준
evals/baseline-notes.md             # 초기 비교 기록
evals/verification-results.md      # 수정 후 정성 검증 결과와 한계
```

평가 기록은 여섯 가지 시나리오를 대상으로 한 정성적 단회 테스트입니다. 무스킬 대조 결과도 양호했으므로, 스킬이 성과를 통계적으로 개선한다고 입증하지는 않습니다.
